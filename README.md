\- English Learning App



\- Website hỗ trợ người dùng tự học và kiểm tra tiếng Anh trực tuyến.



📌 Giới thiệu



\- English Learning App là hệ thống học và kiểm tra tiếng Anh, cung cấp các chức năng hỗ trợ người học cải thiện từ vựng, ngữ pháp, Reading, Listening, Writing và Speaking.



\- Hệ thống cũng hỗ trợ thực hiện các bài kiểm tra tiếng Anh và theo dõi kết quả học tập.

⚙️ Cài đặt

1\. Clone repository

git clone https://github.com/mwc04/web-English.git

cd web-English

2\. Cài đặt Backend

cd english-learning-app/backend

npm install



Tạo file .env và cấu hình các biến môi trường cần thiết.



3\. Chạy Backend

npm start

4\. Cài đặt Frontend



Mở terminal mới:



cd english-learning-app/english-learning-frontend

npm install

5\. Chạy Frontend

ng serve



Sau đó truy cập:



http://localhost:4200

Dự án được phát triển nhằm xây dựng một nền tảng hỗ trợ tự học và kiểm tra tiếng Anh trực tuyến, đồng thời phục vụ quá trình thực tập và phát triển đồ án tốt nghiệp.
